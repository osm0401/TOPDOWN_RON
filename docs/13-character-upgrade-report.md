# 캐릭터 업그레이드 결과

모델 파일은 그대로 두고, 게임이 불러온 모델을 사람마다 다르게 꾸미고 더 세밀하게 움직이게 했어요. 새 3D 모델 파일(얼굴·몸이 다른 사람)은 Antigravity가 만들 수 있게 안내서(`docs/09-3d-models-antigravity.md` 2-1)를 늘렸어요.

## 1. 사람마다 다른 모습
- 모델 파일 하나로 여러 사람을 만들어요(`src/game/people_looks.gd`, `src/game/character.gdshader`).
  - 윗옷·바지 색: 적 윗옷 8가지·바지 5가지, 민간인 셔츠 9가지·바지 6가지. 주름·주머니 명암은 그대로 남아요.
  - 피부색 6가지
  - 키 0.93~1.06배, 체격(폭) 0.94~1.1배
  - 머리카락: 머리에 칠해요(이마선, 뒤통수, 결). 민간인 75%, 적 35%. 색 7가지
  - 착용품: 비니, 선글라스, 두건(얼굴 가림), 배낭(적) / 비니, 안경, 배낭(민간인)
- 사람 번호로 정해서 **호스트와 클라이언트가 같은 사람을 봐요.**
- 단서는 그대로 유일해요: 노란 옷·모자는 색 목록에 없고, 빨간 모자 단서가 있는 사람은 비니를 쓰지 않아요.
- 값 바꾸기: `data/view3d.json` `people`
- 모델 종류 파일(`enemy_2.glb` … `enemy_9.glb`, `civilian_2.glb` …)이 있으면 사람마다 그중 하나를 골라요. 지금은 파일이 없어서 기본 모델만 써요.

## 2. 총상
- 맞은 쪽(앞·뒤·옆)의 몸통에 피가 옷에 스며요. 젖은 피는 더 어둡고 반짝여요.
- 쓰러진 사람은 피가 천천히 번져요(최대 크기까지). 한 사람에 최대 4곳.
- 경찰도 맞으면 생겨요. 비살상 소총은 안 생겨요.
- 값: `data/view3d.json` `effects.wound`

## 3. 장비와 경찰 장구
- 권총: 슬라이드 홈, 배출구, 가늠쇠, 레일, 손잡이 패널, 방아쇠울, 라이트를 더 세밀하게
- 빨간 모자(단서): 솔기, 숨구멍, 휜 챙, 안쪽 땀받이
- 경찰: 오른팔에 플레이어 색 패치(어두운 방에서도 보임), 가슴에 무전기
- 새 착용품 모양: 비니, 안경, 선글라스, 두건, 배낭(`src/game/gear_models.gd`)

## 4. 움직임
- 겁먹은 민간인(항복, 숨기, 쓰러짐, 수갑)은 몸을 떨고 숨이 빨라요. 무장 해제된 적도 조금 떨어요.
- 서 있을 때 몸이 조금씩 흔들려요.
- 기절하거나 뒤에서 맞아 죽으면 엎드려 쓰러지고, 앞에서 맞아 죽으면 뒤로 쓰러져요.

## 5. 모델 검사 도구
- `tools/models/check_models.gd`가 그림을 한 장 더 저장해요: `<세트>_people.png` (게임이 꾸민 적 9명, 민간인 9명, 마지막 사람은 총상)
- `enemy_2.glb` 같은 종류 파일도 검사하고 그림에 섞어 보여 줘요.

## 검증 (이 PC)
- 단위 테스트 283개, 통합 테스트 260개 전부 통과
  - 모양 검사: 모든 꼭짓점의 원래 위치 기록, 몸 윤곽(가슴 앞·등·머리), 사람마다 다른 색과 체격
  - 총상: 앞에서 맞으면 가슴, 뒤에서 맞으면 등, 최대 4곳, 번짐 한계
  - 종류 파일: `enemy_2.glb`를 넣으면 두 번째 적 모델로 잡힘
  - 같은 번호는 항상 같은 모습, 민간인 12명 중 셔츠 5가지 이상·키 6가지 이상·착용품 4개 이상, 노란 옷·모자 없음
- 고친 것: 점이 적은 모델(상자 등)에서 몸 윤곽이 0이 되던 문제(이제 모델 전체 크기를 씀)
- 고친 것: 매복·후퇴 시험이 가끔 실패하던 문제(난수 고정)
- 그림 확인: 사람 18명 시트, 게임 화면(단서 용의자, 쓰러진 용의자, 총 맞은 용의자)

## 미검증 / 한계
- 새 얼굴·몸(종류 파일)은 아직 없어요. Antigravity로 만들면 바로 섞여 나와요(안내서 2-1, 붙여 넣을 문장은 맨 아래).
- 머리카락은 칠한 것이라 짧은 머리만 돼요.
- 옷 색 바꾸기는 지금 세 모델에 맞춰 확인했어요. 새 모델은 검사 그림으로 확인해야 해요.
- 두 PC 사이 실제 연결에서는 시험하지 않았어요(같은 번호 → 같은 모습이라 맞을 거예요).
