# 엄폐 / 발소리·재장전 소리 / 장비 선택 / 2인 일치 확인 결과

## 1. 가구 엄폐
- 키 큰 가구(옷장, 책장, 냉장고, 찬장, 선반, 서류함)는 벽처럼 시야와 총알을 막아요.
- 낮은 가구는 바로 뒤에 있는 사람에게 오는 총알을 일정 확률로 막아요(`data/tuning.json` `cover`).
  - 단단한 것(조리대, 아일랜드 식탁, 책상, 상자, 드럼통 등) 70%, 푹신한 것(소파, 안락의자, 침대) 40%
  - 뒤에 웅크리거나 누워 있으면 1.3배
  - 엄폐물에 바짝 붙어 쏘는 사람의 총알은 넘어가요(쏘는 쪽 30 px 안의 가구는 무시).
  - 막힌 총알은 가구에 총알 자국과 나무 조각·솜을 남겨요.
- 탄약: FMJ는 낮은 엄폐물을 더 잘 뚫고(피해 2), JHP는 피해가 크지만(3) 더 자주 막혀요. 비살상 소총은 잘 막혀요.
- 적의 행동:
  - 공격 중에 총을 맞거나 위협 사격을 받으면, 가까운 가구 뒤(경찰과 자신 사이에 가구가 오는 자리)로 달려가 웅크려요.
  - 같은 방 안에서만 찾고, 다른 사람이 이미 차지한 자리는 피해요.
  - 엄폐 중에는 위협이 있던 쪽을 보고, 사격 간격이 2배로 길어져 가끔 일어나 쏴요.
  - 민간인도 숨을 때 가구 뒤를 찾아요.
- 부엌 가운데에 아일랜드 식탁(`island`)을 추가했어요(뒤쪽 벽 타일 없음, 과일 그릇).
- 시험 장면: `-- --solo --scenario=cover --zoom=0.6`

## 2. 발소리와 재장전 소리
- 발소리는 바닥에 따라 달라요: 나무, 타일(부엌·사무실·복도), 카펫(깔개 포함), 콘크리트(창고·보도), 잔디, 아스팔트.
  - 바닥 이름 → 소리 종류: `data/audio.json` `step_surfaces`
  - 뛰면 더 크게, 걸으면 작게(`steps`)
- 3D 화면에서는 걷는 동작에서 발이 땅에 닿는 순간(보폭의 1/4, 3/4 지점)에 소리가 나요.
  - NPC 발소리도 들려요. 보이지 않는 NPC도 위치로 보폭을 계산해서 벽 너머 발소리가 들려요(벽·문 뒤는 먹먹하게).
  - 2D 화면에서는 예전처럼 이동 거리마다 나요(바닥 소리는 같음).
- 재장전은 손이 닿는 때에 맞춰 세 번 소리가 나요: 탄창 빼기(22%) → 탄창 넣기(78%) → 노리쇠(92%).
  - 통째 재장전 녹음(`reload_N.wav`)만 있고 부분 녹음이 없으면, 예전처럼 시작할 때 통째로 재생해요.
- 파일로 바꾸기: `footstep_<바닥>_N.wav`, `mag_out_N.wav`, `mag_in_N.wav`, `bolt_N.wav` (`assets/audio/README.md`)
- 레오낫 소리 가져오기(`tools/audio/import_ron.py`)가 탄창 빼기/넣기/노리쇠 소리도 따로 뽑아요. 다시 가져오면 적용돼요.
- 레오낫 발소리는 아직 가져오지 않아요(폴더 구조를 모름). 지금은 합성음이에요.

## 3. 출동 전 장비 선택
- 브리핑 화면 오른쪽 아래에서 클릭으로 골라요: 주무기(살상/비살상 소총), 탄약(FMJ/JHP, 살상 소총만), 도구 2칸(문틈 카메라/락픽/테이저).
- 버튼에 마우스를 올리면 설명이 나와요. 동료가 고른 장비도 보여요.
- Enter(준비 완료)를 누르면 잠겨요.
- 2인: 클라이언트가 고르면 호스트가 확인(모르는 장비, 준비 후 변경은 거절)해서 양쪽에 보내요.
- 고른 장비는 다시 하기(재시도) 때도 유지돼요. 혼자 하기는 로비에서 고른 장비가 기본이에요.
- 기본값과 선택지, 이름, 설명: `data/loadout.json`

## 4. 2인 일치 확인
- 리눅스용 두 프로세스 시험 `tests/net_smoke.sh <godot> [장면...]`을 추가했어요(윈도우용은 `net_smoke.ps1`).
- 호스트와 클라이언트를 띄워 마지막 상태(위치, 문, 경찰, 무기, NPC, 임무, 점수, **장비**)가 똑같은지 비교해요.
- `SHOTS=폴더`를 주면 양쪽 화면을 찍어요.
- 고친 것: 시험 모드 클라이언트가 호스트가 끝난 뒤 로비로 돌아가 멈춰 있던 문제(이제 바로 종료). 호스트는 클라이언트가 기록을 마칠 때까지 기다려요.

## 검증 (이 PC)
- 단위 테스트 269개, 통합 테스트 249개 전부 통과
  - 엄폐: 옷장이 시야를 막음, 소파 너머 사격, 엄폐물에 기대 쏘기, FMJ/JHP 차이, 엄폐 자리 찾기와 웅크리기
  - 발소리: 바닥 판정(깔개/부엌/복도/거리/보도/잔디), 보폭당 2걸음, 발이 다 뻗었을 때, 안 보이는 NPC 발소리
  - 재장전: 부분 소리 시점, 녹음 우선순위
  - 장비: 선택지 검사, 준비 후 잠김, 재시도 유지, 탄약별 실제 피해
- 소리 도구 테스트(`tools/audio/test_tools.py`, `test_import_ron.py`) 통과
- 두 프로세스 시험(`tests/net_smoke.sh`, 이 PC 안에서 호스트+클라이언트): 8개 장면 모두 양쪽 마지막 상태가 같음

| 장면 | 확인한 것 | 결과 |
|---|---|---|
| (기본 진행) | 이동, 문, 카메라, 사격, 명령, 재장전 | 같음 |
| briefing | 브리핑 화면, 기본 장비 | 같음 |
| loadout | 양쪽이 장비를 고름, 한 프레임에 두 번 고르기, 준비 후 변경 거절 | 같음 |
| doors | 열림·약간 열림·닫힘 문 | 같음 (시험용 장면이 문 상태를 안 보내던 것 고침) |
| shots | 벽 총알 자국, 용의자 사격 | 같음 |
| cover | 적이 아일랜드 식탁 뒤에 웅크림, 식탁에 맞는 총알 | 같음 |
| result | 결과 화면, 점수 | 같음 |
| vote | 재시도 투표 후 양쪽 새 월드 | 같음 |

- 창 모드로 양쪽 화면을 찍어 비교(동료를 호스트 옆에 세우는 시험 단계 `bring_partner` 추가)
- 고친 것: 클라이언트가 장비를 빠르게 두 번 고르면 두 번째가 첫 번째를 되돌리던 문제(이제 고른 즉시 자기 화면에 반영하고, 호스트 답으로 확정)
- 시험 도구 고친 것: 한쪽이 느리면(그래픽 카드 없이 그리기) 두 쪽이 서로 다른 순간을 기록하던 문제. 이제 클라이언트가 끝에 닿았다고 알리면 호스트가 기록하고 답하고, 그다음 클라이언트가 기록해요. 클라이언트는 호스트가 나가면 바로 끝나서 한 번 도는 시간이 약 12분 → 3분으로 줄었어요.

## 미검증 / 한계
- 소리는 귀로 들어 보지 못했어요. 주파수만 확인했어요(카펫·나무는 낮고 타일은 높음).
- 엄폐 확률과 사격 간격은 모두 임시값이에요.
- 두 PC 사이의 실제 인터넷 연결에서는 시험하지 않았어요.
