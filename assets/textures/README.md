# assets/textures

- 넣는 곳: `assets/textures/<set>/<이름>.png`(또는 `.jpg`). `<set>`은 `data/view3d.json`의 `characters.set`이고, 지금은 `gemini`예요.
- 이름 목록, 크기, 만드는 법: `docs/09-3d-models-antigravity.md`의 3-2
- 만드는 사람: Antigravity(Gemini)
