# 단계 2 결과 — 회색 상자 기본 전투

## 구현 범위
- 맵: 방 5개 + 복도 + 외부 탈출 구역 + 문 6개 (`data/map_01.json`, 좌표는 임시)
- 이동/충돌: 호스트가 `CharacterBody2D`로 이동·벽 충돌 처리. 닫힌 문은 막고 열린 문은 통과
- 시야 가림: 각자 자기 시점의 가시 영역(광선 기반)만 보이고 나머지는 어둡게. 팀원은 항상 표시
- 문: 가까운 문 1개를 E로 열기/닫기. 문 테두리·색이 마지막으로 조작한 플레이어(파랑=호스트, 주황=클라이언트)를 표시
- 소리 이벤트: 발소리/총성/문을 파문으로 표시 (F3로 끄기). 화면에 적 위치를 표시하지는 않음
- 권총: 클릭 발사, R 수동 재장전, 탄창별 잔탄 보존(현재 탄창 + 예비 탄창 목록), 호스트가 판정
- 카메라: 내 캐릭터 추적 + 마우스 방향 약간 오프셋
- 샘플 적: 시야(벽/닫힌 문)가 막히지 않고 200px 안일 때만 "경계"
- 모든 수치: `data/tuning.json` (임시값)

## 구조
| 파일 | 역할 |
|---|---|
| `src/game/level.gd` | 맵 로드, 벽/문 물리 바디, 문 상태, 광선(시야/총알), 가시 영역 |
| `src/game/net_world.gd` | 호스트 시뮬레이션과 동기화(RPC). 입력은 호스트가 검증 |
| `src/game/world_view.gd` | 그리기, 안개, 카메라, HUD (상태를 읽기만 함) |
| `src/core/weapon_state.gd` | 탄창/재장전 규칙 (노드 없는 순수 로직) |

## 검증 (이 PC)
- 단위 테스트 68개 통과: 방 코드, 무기, 맵(벽/문 시야 차단, 문 열림, 플레이어 벽 충돌, 가시 영역)
- 두 프로세스 시험(localhost) 3회 + VPN 주소 경유 1회: 호스트/클라이언트 최종 상태 일치
  (위치, 문 열림·조작자, 적 상태, 점수, 양쪽 탄창)
- 창 모드 스크린샷으로 시야 가림, 열린 문 부채꼴 시야, 소리 파문, 총알 궤적, 피격 표시 확인
- 시야 계산 비용: 프레임당 약 1ms

## 미검증 / 한계
- 사람이 직접 조작한 감각(이동 속도, 조준, 카메라 오프셋)
- 실제 네트워크(두 PC)에서의 지연 체감. 클라이언트 이동은 여전히 예측 없음
- 벽은 시야 경계에서만 보임 (벽 두께 안쪽은 어둡게 처리됨)
- 총알은 샘플 적에게만 판정, 플레이어 간 사격(아군 사격)은 아직 없음
- 오디오 없음: 소리는 시각 파문으로만 표시
