# 3D 화면 시험판 결과 — 비스듬한 3D 카메라 (도형 임시 표현)

## 목적
2D 회색 상자 화면과 비스듬한 3D 화면을 같은 게임 상태로 나란히 비교해, 에셋을 입히기 전에 방향을 정한다.

## 쓰는 법
- 게임 중 `F5`: 2D <-> 3D 전환 (HUD, 브리핑, 결과 화면은 그대로 2D)
- 기본은 3D로 시작(`data/view3d.json`의 `start_3d`). 2D로 시작: 실행 인자 `-- --view2d` (예: `Godot.exe --path D:/TOPDOWNRON -- --solo --view2d`), `-- --view3d`는 3D로 시작
- 값 조정: `data/view3d.json` (카메라 각도/거리/시야각, 벽 높이, 벽 낮춤, 조준 높이) — 모두 임시값

## 구조
| 파일 | 역할 |
|---|---|
| `src/game/world_view_3d.gd` | 3D 화면 (도형만 사용). 시뮬레이션 상태를 읽기만 함 |
| `src/game/world_view.gd` | F5 전환. 시야 다각형/손전등/NPC 보임 계산은 계속 여기서 하고 3D가 그 결과를 재사용 |
| `src/game/net_world.gd` | `mouse_world` 훅 하나만 추가: 3D가 커서의 지면 좌표를 넘겨주면 기존 조준 계산이 그대로 동작 |
| `data/view3d.json` | 3D 설정값 |

규칙, AI, 네트워크, 점수, 데이터 파일은 바뀌지 않았다 (3D로 켠 실행과 2D 실행의 최종 상태가 동일).

## 구현된 표현
- 바닥, 어두운 방, 탈출 구역, 벽(상자), 문(상태/색/잠금 표시)
- 시야 안개: 시야 다각형 밖은 바닥 안개, 다각형에 닿지 않는 벽/문은 숨김
- 플레이어/NPC (캡슐+머리): 서기, 엎드림(쓰러짐), 구속(웅크림+수갑), 항복(손 든 모습), 숨음(웅크림), 사망(누움)
- 인물 모델(`assets/characters/`, 있으면 캡슐 대신): 불러올 때 뼈대 14개를 자동으로 붙이고(`src/game/character_models.gd`), 상태에 맞는 자세를 매 프레임 계산한다(`src/game/character_anim.gd`): 걷기·달리기, 소총·권총 겨누기, 재장전, 무릎 꿇고 작업, 위협 겨누기, 항복(손 들기), 숨어 머리 감싸기, 무릎 꿇고 수갑, 엎드려 손 머리 뒤, 쓰러짐, 숨쉬기, 움찔, 반동. 총·수갑·모자·완장은 `src/game/gear_models.gd`. 자세한 내용은 `assets/characters/README.md`. 값: `data/view3d.json`의 `characters.walk`, `characters.pose`
- 모델 묶음: `data/view3d.json`의 `characters.set`(지금 `"gemini"`) 폴더의 인물(`assets/characters/<set>/`)과 장비(`assets/gear/<set>/`, 손잡이·총구 등은 빈 노드로 표시)를 먼저 쓰고, 없는 것은 기존 모델과 코드로 만든 장비를 쓴다. 3D 모델은 Antigravity가 만들고(`docs/09-3d-models-antigravity.md`), `tools/models/check_models.gd`가 게임과 같은 방식으로 읽어 검사하고 자세 그림을 저장한다
- 장면 꾸미기:
  - 방마다 바닥과 벽 재질이 달라요(`data/map_01.json` rooms의 floor·wall, 값은 `data/view3d.json` surfaces).
    - A 거실: 나무 바닥, 따뜻한 벽
    - B 침실: 카펫, 푸른 벽
    - C 사무실: 타일 카펫, 흰 벽
    - D 부엌: 체크 타일, 노란 벽
    - E 창고: 콘크리트, 블록 벽
    - 복도
  - 벽:
    - 윗면은 어둡게 칠해 평면도처럼 읽혀요.
    - 안쪽에는 걸레받이, 바깥에는 벽돌과 바닥 띠가 있어요.
    - 방을 둘러싼 바깥 벽에는 창문이 있어요. 밝은 방의 창은 밖에서 보면 빛나요.
  - 바깥: 잔디, 인도, 아스팔트, 연석, 주차선, 가로등 2개, 경찰차(경광등이 빨강·파랑으로 깜빡임), 탈출 구역 테두리, 콘
- 가구(`data/map_01.json` props, 모양은 `src/game/prop_models.gd`): 56개
  - 종류: 소파, 탁자, 침대, 옷장, 책상·모니터, 사무 의자, 서류함, 냉장고, 싱크대, 가스레인지, 선반, 상자, 드럼통, 그림, 화이트보드 등
  - 사람(경찰의 몸, NPC 길 찾기)의 이동만 막아요. 시야, 총알, 소리는 통과해요.
  - 깔개, 그림, 화이트보드, 콘은 아무것도 막지 않아요.
  - 키 큰 가구와 벽에 건 것은 벽처럼 경찰 앞을 가리면 낮아져요.
  - 어두운 방의 스탠드와 화면은 꺼져 있어요.
  - 2D 화면에는 갈색 사각형으로 나와요.
- 문:
  - 문틀(양쪽 몰딩, 문 위 벽, 문턱)과 판넬 문짝(손잡이, 경첩, 발판)이 있어요.
  - 문짝은 경첩을 축으로 열려요. 활짝 열면 180도 돌아 옆 벽에 붙고, 자리가 없으면 90도만 열려요.
  - 약간 열기는 규칙에 있는 틈만큼만 돌아요.
  - 잠긴 문 위에는 빨간 자물쇠가 떠 있어요.
- 총을 쏘면 남는 것:
  - 벽과 문에 총알 자국, 회반죽 먼지와 불꽃
  - 맞은 사람의 피와 바닥 핏자국
  - 총구 연기, 총 오른쪽으로 튀어나가 바닥에 구르는 탄피
  - 시신 밑으로 번지는 피 웅덩이
  - 개수는 상한이 있고, 오래된 것부터 지워져요(`data/view3d.json` effects).
- 현실감(`data/view3d.json` graphics, wear):
  - 조명: 빛이 벽·바닥에 튀어 번지는 효과(SDFGI), 부드러운 그림자, 사진 같은 색 처리(AgX), 매끈한 바닥의 반사, 화면 가장자리 어둡게
  - 그래픽 품질: 게임 중 **F8**로 높음 → 보통 → 낮음을 바꿀 수 있어요. 느린 PC는 낮음으로 하세요. 시험용 인자 `--quality=low`
  - 재질: 바닥과 벽에 큰 얼룩·닳은 자국, 아스팔트·콘크리트의 잔 알갱이, 타일의 둥근 모서리
  - 생활 흔적(매번 같은 자리): 벽 아래 때, 문턱 앞 신발 자국, 벽의 금, 사무실·복도에 흩어진 종이, 부엌 물 얼룩, 창고와 거리의 기름 얼룩, 바깥 벽의 빗물 자국
  - 사진 질감: `assets/textures/<set>/<이름>.png`가 있으면 무늬 대신 써요(Antigravity가 만들 수 있게 `docs/09` 3-2에 목록을 적었어요).
  - 경찰 구분: 몸을 감싸던 빛을 줄이고, 발밑 색 고리(파랑·주황)로 구분해요.
- 테두리 계단 현상 줄이기(MSAA, 품질에 따라 4x / 2x / 끔)
- 시험용 장면: `-- --solo --scenario=doors | shots | outside`, 확대는 `--zoom=0.5`
- 마우스 휠: 카메라 확대/축소(글씨 크기는 그대로)
- 단서: 붉은 모자(머리 위 원통), 노란 완장(몸 옆 상자), 떨어진 무기
- 손전등 원뿔, 레이저, 총탄 궤적, 소리 파문, 말풍선, 행동 진행률, 상태 표시(? ! !!)
- 문틈 카메라 위치 표시

## 검증 (이 PC)
- 단위 테스트 226개, 통합 테스트(3D 11개 추가) 전부 통과
- 3D 커서 -> 지면 좌표 변환, 조준 훅 설치/해제, 안개 메쉬, 시야 판정, 벽 낮춤
- 창 모드 스크린샷: 단서 장면, 기본 협동 장면 (2D 대비 같은 상태)
- 두 프로세스 스모크 통과, 3D 실행과 최종 상태 동일

## 미검증 / 한계
- 사람이 직접 한 조작감 (3D 조준이 2D만큼 정확한지), 수치 모두 임시
- 벽 옆면 안개 처리 없음 (일부만 보이는 벽은 통째로 보임), 그림자/실제 손전등 광원 없음
- 벽 가림은 "플레이어 바로 남쪽 벽 낮춤"만 처리. 다른 위치의 가림(예: 문 너머 방 안쪽)은 카메라 각도에 따라 남음
- 자세는 코드로 계산한 것이라 손목·손가락은 움직이지 않고, 생성 모델에서 소매가 몸통에 붙어 있던 곳은 팔을 앞으로 들면 옷이 천처럼 늘어난다(팔을 몸에서 뗀 모델로 바꾸면 줄어든다)
