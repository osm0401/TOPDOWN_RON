# 그래픽 현실감 작업 결과 (사진 질감, 총격 흔적, 피)

## 1. 사진 질감과 노멀맵·거칠기 맵 (`src/game/surface.gdshader`, `src/game/surface_maps.gd`)
- 바닥·벽·땅의 사진(`assets/textures/<set>/<이름>.jpg`)에 더해 `_normal`(노멀맵), `_rough`(거칠기), `_ao`(틈새 그늘) 그림을 읽어요. 노멀맵이 있으면 벽돌 줄눈, 나뭇결이 빛을 받아 실제로 울퉁불퉁해 보여요.
- 벽에 붙는 사진은 이제 똑바로 서요(전에는 위아래가 뒤집혔어요).
- 가구 재질(나무, 천, 돌)도 같은 이름 규칙으로 사진을 쓸 수 있어요(`wood_mid.jpg` 등, 사진 1장 = 1 m).
- 사진이 없으면 지금처럼 코드로 그린 무늬를 써요. 아무것도 넣지 않으면 화면은 그대로예요.
- 무료 질감 넣는 도구: `tools/textures/import_textures.py`(.bat). ambientCG / Poly Haven에서 받은 zip을 이름만 바꿔 넣으면 알맞게 정리해요. 방법: `docs/09-3d-models-antigravity.md` 3-2.

## 2. 총구 연기, 벽 피격 먼지·파편 (`src/game/world_view_3d.gd`)
- 쏠 때마다 총구 연기가 총이 향한 쪽으로 밀려 나가며 2.4초 동안 떠 있다가 사라져요. 소총은 권총보다 1.5배.
- 벽·문·가구에 맞으면: 먼지가 더 많이 튀고, 천천히 가라앉는 먼지 구름이 2.6초 남고, 작은 파편 6개가 튀어나와 바닥에 떨어져 남아요(맵 전체 160개까지). 소파·매트리스는 파편 대신 솜.
- 값 바꾸기: `data/view3d.json` `effects.smoke`, `effects.impact`

## 3. 피 (`src/game/world_view_3d.gd`)
- 피 웅덩이나 핏자국을 밟으면 다음 10걸음 동안 신발 자국이 남고 점점 옅어져요(경찰·적·민간인 모두).
- 다친 사람(체력이 줄어든 사람)은 걸을 때 핏방울을 떨어뜨려요.
- 맞은 자리의 핏자국은 2.5초 동안 번져 나가요.
- 시신 밑 웅덩이는 6초 동안 빨리 퍼진 뒤 90초 동안 1.1 m → 1.6 m로 천천히 더 번져요.
- 모든 피는 2분에 걸쳐 검붉게 말라요.
- 값 바꾸기: `data/view3d.json` `effects.blood_trail`

## 4. 가구 모델 (사진 같은 소파·책상)
- 이 작업에서는 파일을 만들지 않았어요. 클라우드에서 무료 모델 사이트(Poly Haven 등)에 접속할 수 없었고, Higgsfield 크레딧은 거의 없어서 쓰지 않았어요.
- PC에서 하는 방법은 `docs/09-3d-models-antigravity.md` 3-1(이름, 크기, 방향 규칙)에 있어요. Poly Haven Models(polyhaven.com/models, CC0)에서 소파·의자·탁자를 받아 Antigravity에게 3-1 규칙대로 `.glb`로 바꿔 `assets/props/gemini/<종류>.glb`에 넣게 하면 돼요.

## 검증 (클라우드, Godot 4.7.2)
- 단위 테스트 285개, 통합 테스트 271개 전부 통과. 새 통합 테스트 11개: 웅덩이가 계속 번짐, 핏자국 번짐, 피가 마름, 피 발자국과 옅어짐, 핏방울, 연기·먼지가 오래 남음, 파편이 떨어져 바닥에 남음, 노멀맵·거칠기 맵 읽기
- 질감 도구 자체 테스트 8개 통과(ambientCG zip, Poly Haven 폴더, DirectX 노멀맵 뒤집기, 큰 그림 줄이기)
- 실제 그래픽(Forward+, 소프트웨어 Vulkan)으로 화면 확인: 복도에서 벽 사격(먼지 구름, 파편, 탄피, 총구 연기), 피 웅덩이와 발자국·핏방울, 시험용 벽돌 그림+노멀맵을 바닥과 벽에 씌운 모습. 셰이더 오류 없음.

## 미검증 / 한계
- 진짜 사진 질감은 아직 들어 있지 않아요(PC에서 받아야 해요). 시험용으로 만든 벽돌 그림으로만 확인했어요.
- 실제 그래픽 카드에서 FPS는 재 보지 않았어요. 연기와 파편은 개수 제한이 있어 무겁지 않을 거예요.
- 발자국은 위에서 보면 작아서(30 cm) 가까이 확대해야 신발 모양이 보여요.
