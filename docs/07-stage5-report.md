# 단계 5 결과 — 귀환 / 증원 / 결과 투표

## 구현 범위
- 증원 1회: 건물 밖에 대기하던 적 2명이 도착. 도착 시간은 난이도 프리셋 (쉬움 420초 / 보통 300초 / 어려움 210초, 임시값)
- 사전 신호: 도착 8초 이상 전에 무전 문구 + 외부 사이렌 파문. 큰 소리로 앞당겨져도 경고가 항상 먼저
- 앞당김: 걷어차기/총성/비명/테이저 소음, 그리고 적이 플레이어를 알아챈 동안 시계 2배 속도
- 귀환 판정: 도착 전에 탈출하면 성공(증원 없음). 도착한 증원 적은 사살/구속해야 귀환 인정
- 결과 투표: 같은 임무 재시도 / 메인 로비. 같아야 진행, 다르면 재투표 1회, 라운드당 15초, 그래도 다르면 로비
- 재시도: 호스트와 클라이언트 월드를 모두 새로 만들어 브리핑부터 재시작 (연결 유지)
- 싱글: 혼자 투표(타이머 없음)

## 구조
| 파일 | 역할 |
|---|---|
| `src/core/reinforcement_clock.gd` | 증원 시계 (순수): 대기 -> 경고 -> 도착, 소음 앞당김 |
| `src/core/vote_state.gd` | 결과 투표 (순수): 라운드, 시간 초과, 로비 폴백 |
| `src/game/npc_director.gd` | 증원 적을 `dormant`(대기)로 두고 도착 시 활성화. 대기 중에는 보이지 않고 맞지도 않음 |
| `src/game/net_world.gd` | 시계/투표를 호스트가 진행하고 `rpc_mission`, `rpc_vote`, `rpc_restart`, `rpc_to_lobby`로 복제 |
| `src/ui/main.gd` | 재시도 시 월드 재생성, 로비 복귀 |

## 검증 (이 PC)
- 단위 테스트 226개: 증원 시계(경고 우선, 소음, 최소 여유), 투표(일치, 재투표, 시간 초과, 로비, 싱글, 직렬화), 대기 중 증원 적 격리와 활성화
- 통합 테스트 78개: 소음/경보로 시계 앞당김, 경고 후 도착, 도착한 적이 귀환을 막음, 도착 전 탈출 성공, 투표 전체 흐름(재시도/재투표/로비/시간 초과/싱글)
- 두 프로세스 시험: 재시도 투표(의견 불일치 -> 재투표 -> 재시도) 후 양쪽이 같은 새 월드로 시작, 증원 경고와 도착 로그, 기본 시나리오 일치
- 창 모드 스크린샷: 투표 화면(재투표 안내), 증원 도착

## 미검증 / 한계
- 사람이 직접 한 증원 긴장감과 수치 균형 (모두 임시값)

- 재시도 시 장비 재선택 화면은 없음 (장비 선택 UI 자체가 아직 없음)
