# 적 AI 강화 결과 — 경계, 조준, 버티기, 매복, 후퇴

적이 경찰 쪽으로 그냥 걸어오던 것을 고쳐서, 더 조심스럽고 위험하게 만들었어요. 모든 수치는 임시값이고
`data/tuning.json`의 `npc`에 있어요. 난이도마다 `data/difficulty.json`의 `tactics`(쉬움 0.6 / 보통 1.0 / 어려움 1.4)를 곱해요.

## 1. 경계 상태
- 총소리(가장 크게), 발로 차기·비명, 문소리·발소리, 동료의 경고를 들으면 적이 긴장해요.
- 긴장은 30초(`alert_decay_s`)에 걸쳐 풀려요.
- 긴장한 적이 경찰을 보면 반응 시간과 총을 겨누는 시간이 최대 절반(`alert_react_mult`)으로 줄어요.
  - 시험: 총소리를 들은 적 0.40초, 조용하던 적 0.70초

## 2. 조준
- 경찰을 처음 보고 쏘는 첫발은 정확도 ×0.6이에요.
- 1.2초(`aim_settle_s`) 동안 계속 보고 있으면 ×1.25까지 올라가요. 오래 서 있으면 위험해요.
- 위협 사격을 받는 중에는 ×0.6.
- 경찰이 움직이면 맞히기 어려워요(최고 속도일 때 ×0.65). 서 있는 경찰은 그대로예요.
- 결과: 짧게 엿보고 움직이는 쪽이 유리하고, 멈춰 서서 오래 노출되면 불리해요.

## 3. 놓친 경찰 기다리기(각 잡기)
- 싸우던 경찰이 시야에서 사라지면, 바로 찾으러 오지 않아요.
- 마지막으로 본 곳을 2~6초(`hold_s`) 더 겨누고 기다려요.
- 그 사이 경찰이 다시 나타나면 이미 겨누고 있어서 바로 쏴요.
- 아무도 안 오면 그때 확인하러 가요.

## 4. 매복
- 다른 방에서 소리가 나면, 무장한 적의 절반(`ambush_chance`)은 그쪽으로 걸어가지 않아요.
- 대신 자기 방 안에서 그 소리 쪽 문을 겨누는 자리로 달려가 기다려요.
  - 자리: 문이 보이고 90~420 px 떨어진 곳, 가능하면 낮은 가구 뒤, 지금 자리에서 가까운 곳
  - 매복 중에는 문을 직접 열지 않아요. 경찰이 문을 열고 들어오면 바로 발견해요.
- 6~14초(`ambush_s`) 동안 아무도 안 오면 확인하러 가요.
- 같은 방에서 난 소리면 예전처럼 바로 확인하러 가요.
- 시험 장면: `-- --solo --scenario=ambush` (방 B 문 앞에서 발차기 소리 → 문을 열면 적이 문을 겨누고 있음)

## 5. 부상 후퇴
- 다쳐서 체력이 절반 이하가 된 무장한 적은 먼저 항복 확률(`hurt_surrender_chance`)을 굴려요.
- 항복하지 않으면 절반(`retreat_chance`)은 경찰에게서 먼 방으로 물러나요.
- 물러난 뒤에는 가구 뒤에 숨어 총을 들고 기다리다가, 경찰이 보이면 다시 싸워요.
- 후퇴는 한 번만 해요.

## 화면
- 각을 잡거나 매복 중인 적은 보이지 않는 경찰이 아니라 자기가 보는 방향(문 쪽)으로 총을 들어요.
  - 2D에서는 총 방향으로 흐린 선이 보여요.
  - 2인 플레이에서도 같게 보이도록 네트워크로 보내요.
- 후퇴해서 숨은 적은 웅크린 채 총을 들고 있어요.

## 검증 (이 PC)
- 단위 테스트 283개, 통합 테스트 249개 전부 통과
  - 경계: 반응 속도, 30초에 걸쳐 풀림
  - 조준: 첫발 / 정착 / 위협 사격 중, 움직이는 경찰
  - 놓친 뒤 기다림과 그 뒤의 수색
  - 매복: 다른 방 소리 40번 중 14번 매복, 같은 방 소리는 모두 확인하러 감. 자리로 달려감, 문 쪽 겨눔, 시간이 지나면 확인하러 감, 들어오는 경찰 발견, 방 B에서 문이 보이는 자리, 문을 열지 않음
  - 후퇴: 한 번만
- 두 프로세스 시험: 기본 진행, ambush, cover, shots, loadout, vote 모두 양쪽 같음

## 미검증 / 한계
- 사람이 직접 해 본 난이도 체감(너무 어렵거나 쉬운지)은 확인하지 못했어요. 수치는 모두 임시값이에요.
- 매복 자리는 방 안에서만 고르고, 다른 문으로 돌아서 들어오는 측면 공격은 아직 없어요.
