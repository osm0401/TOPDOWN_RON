# 분위기(비 오는 밤) 작업 결과

밤을 더 어둡고 사실적으로 만들었어요. 방마다 다른 전등, 깜빡이는 등, 비, 젖은 땅, 번개와 천둥, 색 보정이 들어갔어요.

## 1. 빛
- 전체가 더 어두워요(주변광 0.55 → 0.45, 밝기 1.7 → 1.45, 가장자리 어둡게 0.35 → 0.5).
- 방 바닥 종류마다 전등이 달라요: 집(나무·카펫·부엌)은 따뜻한 전구, 사무실·복도는 차가운 형광등. 멀수록 실제 전구처럼 어두워져요.
- 부엌·복도·창고 전등 일부는 가끔 깜빡여요(등마다 정해짐, 호스트와 클라이언트가 같아요).
- 가로등은 주황빛 나트륨등. 바깥에는 푸른 달빛이 비치고, 건물 안은 지붕 그림자로 막혀요.
- 값 바꾸기: `data/view3d.json` `lighting` (`room_kinds`, `flicker`, `moon`, `street`)

## 2. 색 보정 (`src/game/post.gdshader`)
- 채도를 낮추고 대비를 올렸어요. 어두운 곳은 차갑게, 밝은 곳은 따뜻하게.
- 필름 알갱이, 화면 가장자리 색 번짐, 더 강한 가장자리 어둡게
- 값 바꾸기: `data/view3d.json` `graphics.grade`

## 3. 비 오는 밤 (`src/game/weather.gd`)
- 빗줄기와 튀는 물방울은 건물 밖 땅 위에만 내려요.
- 젖은 땅: 어둡고 반들반들, 물웅덩이와 빗방울 고리
- 먼 번개: 50~120초마다 달빛이 두 번 번쩍, 1~4초 뒤 천둥
- 끄기: `data/view3d.json` `weather.rain.on`을 `false`로, `wet`를 `{}`로

## 4. 소리
- 빗소리가 계속 나요(건물 안에서는 작고 먹먹하게). 천둥소리.
- 게임에서 나갈 때 계속 나는 소리를 멈춰요(소리가 남아 새던 문제 없음).

## 5. 낡은 느낌
- 벽·바닥 색을 더 어둡고 더럽게, 때 얼룩·금·빗물 자국·기름 얼룩을 더 많이

## 6. 화면 글씨
- 조작법은 처음 20초만 보이고, 그다음은 F1로 켜고 꺼요.
- 글씨를 조용하게(외곽선), 적·민간인 머리 위 AI 상태 글씨는 기본으로 꺼짐(F4 또는 `--debug`로 켬)
- 고친 것: 화면 아래 안내 글(예: "어두운 방이다…")이 오른쪽 아래 목표 상자와 겹쳤어요. 이제 목표 상자 위에 떠요.

## 검증 (클라우드, Godot 4.7.2)
- 단위 테스트 285개, 통합 테스트 260개 전부 통과(빗소리 반복, 천둥 포함)
- 온라인 시험(한 PC에서 호스트 + 클라이언트 두 프로그램) 9가지 전부 통과: 기본 플레이, 브리핑, 장비 고르기, 문, 사격, 엄폐, 매복, 결과, 다시 하기 투표. 두 쪽 마지막 상태가 같아요.
- 실제 그래픽(Forward+, 소프트웨어 Vulkan)으로 화면 확인: 바깥(비·가로등), 사무실(차가운 형광등), 어두운 방, 복도. 셰이더 오류 없음.
- 지금 `main`과 비교: 같은 장면이 더 어둡고 차가워졌어요. 방 전등 색이 방마다 다르게 보여요.
- Windows exe 다시 만들기 성공(`build/windows/TOPDOWNRON.exe`, 약 115MB)

## 미검증 / 한계
- 실제 그래픽 카드에서 FPS는 재 보지 않았어요(클라우드는 소프트웨어 그리기라 느려요). 빗줄기 1800개, 물방울 500개가 무거우면 `weather.rain.drops`를 줄이거나 F8로 품질을 낮춰요.
- 번개는 50초 넘게 기다려야 나와서 화면으로는 확인하지 않았어요(테스트로 소리·시간만 확인).
- 클라우드에서 만든 exe에는 레오낫 소리 파일이 없어요(원래 exe에는 안 들어감). 이 PC에만 있는 모델 종류 파일(`enemy_2.glb` 등)은 들어가지 않아요. 그런 파일이 있으면 PC에서 다시 만들어요(`docs/11-windows-build.md`).
