# 3D 모델 만들기 — Antigravity 작업 안내

이 게임의 3D 모델(인물, 장비)은 **Antigravity(Gemini)가 만듭니다.** 이 문서는 Antigravity가 읽고 그대로 따라 하는 작업 지시서입니다. 사람이 할 일은 맨 아래 [사람이 할 일](#사람이-할-일)에 있습니다.

## 0. 원칙

- **기존 파일은 지우거나 덮어쓰지 않는다.** `assets/characters/*.glb`, `src/`, `data/`, `tests/`는 건드리지 않는다. 새 모델은 아래 새 폴더에만 쓴다.
- 만들 것:
  - 인물 3개: `assets/characters/gemini/officer.glb`, `enemy.glb`, `civilian.glb`
  - 장비 7개: `assets/gear/gemini/rifle_lethal.glb`, `rifle_nonlethal.glb`, `pistol.glb`, `camera.glb`, `cuffs.glb`, `cap.glb`, `band.glb`
  - (선택) 가구: `assets/props/gemini/<종류>.glb` — [3-1](#3-1-가구와-경찰차-선택-인물과-장비-다음에)
  - 만든 방법: `tools/models/gemini/` (예: Blender 파이썬 스크립트). 나중에 고칠 수 있게 **반드시 저장**한다.
- 게임은 `data/view3d.json`의 `characters.set`이 `"gemini"`라서 이 폴더를 먼저 읽고, 폴더에 없는 파일은 기존 모델(장비는 코드로 만든 모양)을 쓴다. 그래서 하나씩 넣어도 된다.
- 다 만들면 [5. 확인](#5-확인-반드시)의 검사 도구에서 **FAIL이 0개**가 될 때까지 고친다.

## 1. 공통 규칙 (모든 .glb)

| 항목 | 규칙 |
|---|---|
| 형식 | glTF 2.0 바이너리(`.glb`) 한 파일. 텍스처는 파일 안에 넣는다 |
| 단위 | 미터, 실제 크기 |
| 축 | 위 +Y, 정면(인물의 얼굴, 총구) +Z. **Blender에서는 위 +Z, 정면 −Y** (내보낼 때 "+Y Up"이 바꿔 줌) |
| 변형 | 내보내기 전에 회전·크기를 적용한다 (Blender: Apply All Transforms) |
| 넣지 말 것 | 뼈대(Armature), 애니메이션, 모양 키, 조명, 카메라. 게임이 불러올 때 뼈대를 직접 붙인다(파일에 뼈대가 있으면 버리고 다시 붙임) |
| 재질 | PBR metallic-roughness. 옷·피부·플라스틱은 metallic 0, roughness 0.5~0.95. 금속 부품만 metallic 0.7 이하. 게임 장면에는 비칠 하늘이 없어서 metallic 1은 새까맣게 보인다 |
| 텍스처 | 쓰면 1024×1024 권장(최대 2048). 색만 있는 재질도 된다 |
| 면 | 노멀 포함, 뒤집힌 면 없음 |
| 파일 크기 | 10 MB 이하 |

## 2. 인물 3개

### 모습 (지금 게임에 있는 사람과 같은 사람)

| 파일 | 모습 |
|---|---|
| `officer.glb` | SWAT 경찰. 검은 방탄 헬멧, 남색 긴팔 제복, 검은 방탄조끼(파우치 달림), 검은 장갑, 무릎 보호대, 검은 전술화, 오른쪽 허벅지에 빈 권총집. 두 경찰은 게임이 파랑·주황 윤곽빛으로 구분하므로 색 표시는 넣지 않는다 |
| `enemy.glb` | 빨간 후드티(모자는 내림, 몸에 붙는 핏), 검은 카고 바지, 짙은 부츠, 짧은 검은 머리와 짧은 수염 |
| `civilian.glb` | 대머리 중년 남자. 밝은 청록 긴팔 셔츠(바지 안에 넣음), 베이지 면바지, 갈색 구두 |

- 셋 다 **무기, 모자, 완장, 손에 든 물건 없음.** 총, 빨간 모자, 노란 완장, 수갑은 게임 규칙에 쓰여서 게임이 따로 붙인다.
- 생김새 참고 그림: `assets/characters/source/officer.jpg`, `enemy.jpg`, `civilian.jpg`

### 자세와 비율 (게임이 뼈대를 모양으로 찾기 때문에 중요)

키 1.75 m 기준. 게임이 키는 맞추지만 비율은 그대로 쓴다.

| 부위 | 규칙 |
|---|---|
| 자세 | 똑바로 선 A자 자세, 정면 +Z |
| 팔 | 몸에서 35~40° 벌려 곧게 내린다. **팔과 몸통 사이에 겨드랑이 바로 아래까지 틈이 보여야 한다** |
| 손 위치 | 손 중심이 몸 가운데선에서 좌우로 약 0.33 m(키의 0.19), 바닥에서 약 0.79 m(키의 0.45). 손과 허벅지 사이를 15 cm 이상 띄운다 |
| 손 모양 | 손바닥은 다리 쪽, 손가락은 조금 벌려 틈이 보이게. 장갑 낀 손도 아래팔과 이어진 한 덩어리 |
| 다리 | 발은 어깨너비. 발목부터 허벅지 중간까지 두 다리 사이에 8~12 cm 틈. 긴 코트처럼 다리 사이를 막는 옷은 안 된다 |
| 관절 높이 (키에 대한 비율) | 엉덩이 0.50, 무릎 0.27, 발목 0.05, 가슴 0.71, 목 0.86, 어깨 0.815, 팔꿈치 0.62. 머리 길이는 키의 약 1/7.5 |
| 얼굴 | 무표정, 입 다묾 |

### 메시

- 삼각형 **30,000개 이하** (권장 8,000~20,000). 화면에 사람이 최대 9명 나온다.
- 팔다리는 구부러진다. 길이 방향으로 **4 cm 이하 간격의 고리(edge loop)**를 넣고 팔꿈치·무릎·어깨·엉덩이 근처는 더 촘촘히 한다. 위아래 뚜껑만 있는 원기둥은 구부릴 때 꺾이지 않고 찌그러진다.
- 여러 조각(헬멧, 조끼, 파우치 등)으로 만들어도 된다. 단 **각 팔(위팔 + 아래팔 + 손)은 끊기지 않은 한 조각**이어야 한다. 손만 따로 떠 있는 조각은 안 된다. 팔에 다는 장비(장갑, 팔 보호대)는 팔에 딱 붙인다.
- 옷은 몸에 붙게 한다. 겨드랑이 아래로 늘어지는 천은 팔을 들 때 늘어난다.
- 권총집 같은 장비는 손에서 떨어뜨린다. 손이 닿아 있으면 손과 다리가 붙은 것으로 읽힌다.
- 사람 몸은 원기둥과 구를 따로 이어 붙이기보다 **하나로 이어진 매끈한 메시**(예: Blender 스킨 모디파이어 + 서브디비전, 또는 메타볼 + 리메시)로 만들면 관절이 자연스럽게 휜다.

손 든 모델(`enemy_up`, `civilian_up`)은 만들지 않는다. 지금은 서 있는 모델이 뼈대로 손을 든다.

## 3. 장비 7개

- 원점 (0, 0, 0)은 아래 표의 기준점에 둔다.
- 점은 **빈 노드(Blender: Empty)**로 표시한다. 이름은 `grip`, `fore`, `muzzle`, `light`, `stock`, `mag`이다(대소문자 상관없음, `.001`이 붙어도 됨). 표시가 없는 점은 게임이 코드 모양의 점을 쓰므로 손이 총에서 어긋난다.
- 메시 이름에는 이 단어들을 쓰지 않는다. 예를 들어 손전등 메시는 `flashlight_body`처럼 짓는다.
- 방향: 총구 +Z, 위 +Y, 왼쪽 +X. Blender에서는 총구 −Y, 위 +Z.
- 삼각형은 장비 하나에 **6,000개 이하**로 한다.

| 파일 | 모습, 크기 | 원점 | 필요한 점 |
|---|---|---|---|
| `rifle_lethal.glb` | AR 계열 카빈. 전체 0.85~0.95 m, 검정. 도트 조준경, 총열 옆 무기 라이트 | 오른손이 쥐는 권총 손잡이의 가운데 | `fore`: 왼손이 잡는 핸드가드 아래쪽 / `muzzle`: 총구 끝 / `light`: 라이트 렌즈 앞면 / `stock`: 개머리판 끝(어깨에 닿는 곳) / `mag`: 탄창 아래쪽(재장전 때 왼손이 가는 곳) |
| `rifle_nonlethal.glb` | 비살상 발사기(펌프식 산탄총 모양). 0.85~0.95 m. 개머리판과 펌프 앞손잡이는 **주황색**(비살상 표시), 나머지는 검정. 무기 라이트 | 권총 손잡이 가운데 | 위와 같음 (`fore`는 펌프 손잡이) |
| `pistol.glb` | 폴리머 권총, 총열 아래 라이트. 길이 0.19~0.21 m | 손잡이 가운데(오른손) | `fore`: 왼손이 감싸는 곳(손잡이 왼쪽 +X, 조금 앞) / `muzzle` / `light` / `mag`: 탄창 바닥 |
| `camera.glb` | 문틈 카메라. 손잡이 + 작은 화면 + 앞으로 뻗은 0.35 m 막대 끝의 작은 카메라 | 손잡이(오른손) | `fore`: 화면 근처(왼손) |
| `cuffs.glb` | 수갑. 지름 7~8 cm 고리 두 개를 X축으로 약 9 cm 떨어뜨려 짧은 사슬로 잇는다. 고리 구멍은 X축을 향한다(손목이 X축으로 지나감) | 두 고리의 가운데 | 없음 |
| `cap.glb` | 빨간 야구모자. 머리 둘레 지름 약 0.21 m, 챙은 +Z(얼굴 쪽) | 모자 안쪽 아래 테두리(머리에 닿는 둘레)의 가운데 | 없음 |
| `band.glb` | 노란 완장(팔에 감는 띠). 안지름 약 0.13 m, 폭 약 0.09 m, 축은 +Y(팔이 Y축으로 지나감). 단서라서 어두운 방에서도 보이게 노랑이 약하게 빛나게(emission) | 띠의 가운데 | 없음 |

크기가 많이 다르면(센티미터로 만든 경우 등) 게임이 코드 모양의 크기로 맞추고 경고를 낸다.

## 3-1. 가구와 경찰차 (선택, 인물과 장비 다음에)

맵의 가구는 지금 코드로 만든 모양(`src/game/prop_models.gd`)이에요. `assets/props/gemini/<종류>.glb`를 넣으면 그 종류는 파일 모양으로 바뀌어요.

- 종류 이름(파일 이름):
  - 거실·침실: `sofa`, `armchair`, `coffee_table`, `tv_stand`, `bookshelf`, `plant`, `floor_lamp`, `picture`, `rug`, `bed`, `nightstand`, `wardrobe`, `dresser`
  - 사무실: `desk`, `office_chair`, `filing_cabinet`, `water_cooler`, `whiteboard`, `printer_table`
  - 부엌: `fridge`, `counter`, `sink`, `stove`, `dining_table`, `chair`, `pantry`, `trash_bin`
  - 창고: `shelving`, `crate`, `pallet`, `workbench`, `barrel`
  - 바깥: `cone`, `street_lamp`, `police_car`
- 원점: 바닥에 닿는 면(발자국)의 가운데. 앞면은 +Z(Blender −Y), 위는 +Y, 단위는 미터.
- 크기: 실제 크기로 만든다. 게임이 맵의 사각형에 맞게 비율을 지켜 줄이거나 키운다. 크기 참고: `data/map_01.json` props의 rect(px, 50 px = 1 m).
- 벽에 거는 것(`picture`, `whiteboard`): 뒷면을 −Z 쪽에 붙이고, 바닥에서 1.15 m 높이 언저리에 둔다.
- 경찰차: 앞이 +Z. 경광등은 지붕 위 가운데(게임이 빨강·파랑 불빛을 그 자리에 단다).
- 삼각형: 가구 하나 4,000개 이하, 경찰차 15,000개 이하.
- 문은 경첩으로 도는 움직임이 있어서 지금은 코드로 만든다(파일로 바꾸지 않음).

## 4. 만드는 방법 (권장)

- Blender(무료)를 설치하고 모델마다 파이썬 스크립트를 `tools/models/gemini/<이름>.py`로 만든다. `blender --background --python tools/models/gemini/<이름>.py` 한 번으로 `.glb`가 나오게 하면 다시 만들기 쉽다. 다른 도구를 써도 되지만 스크립트는 남긴다.
- Blender glTF 내보내기 설정:
  - 형식: glb, "+Y Up" 켬, "Apply Modifiers" 켬
  - 끔: Animation, Skinning, Shape Keys, 조명, 카메라
  - 장비의 빈 노드(Empty)는 내보내기에 포함한다

## 5. 확인 (반드시)

검사 도구는 게임과 똑같이 모델을 읽어서 뼈대를 붙이고 확인한다.

```
<Godot 실행 파일> --path <저장소 폴더> --script res://tools/models/check_models.gd -- --set=gemini
```

예: `D:\Godot\Godot_v4.7.2-stable_win64.exe --path D:\TOPDOWNRON --script res://tools/models/check_models.gd -- --set=gemini`

- 결과는 한 줄마다 `PASS` / `WARN` / `FAIL`과 고칠 점으로 나온다. 마지막 줄은 `RESULT: n PASS, n WARN, n FAIL`이다.
  - **FAIL이 0개**가 될 때까지 고친다. WARN은 이유가 있으면 남겨도 된다.
  - 실패가 있으면 종료 코드가 1이다.
- 창이 잠깐 뜨고 그림 두 장이 저장된다. **두 장 모두 열어서 직접 본다.**
  - `tools/models/_out/gemini_characters.png`: 인물 정면·옆모습, 그리고 게임 자세 12개(소총·권총 겨누기, 재장전, 문틈 카메라, 달리기, 손 들기, 수갑, 걷기, 놀람, 머리 감싸기)
    - 손이 총 손잡이와 앞손잡이에 닿는지
    - 팔을 들 때 옷이 늘어나지 않는지
    - 다리가 찢어지지 않는지
    - 얼굴이 정면을 보는지
  - `tools/models/_out/gemini_gear.png`: 장비와 점 위치
    - 점 색: grip 흰색, fore 초록, muzzle 빨강, light 노랑, stock 파랑, mag 보라
    - 점이 그 부품 위에 있는지
- 그림 없이 글만 보려면 `--headless`를 붙인다(`Godot ... --headless --path ...`).
- 기존 모델의 결과를 비교용으로 보려면 `-- --set=`(빈 값)으로 실행한다. 기존 경찰과 용의자는 팔과 몸통 사이 틈이 좁아서 WARN이 나온다. 새 모델은 이보다 좋아야 한다.

## 6. 올리기

1. 저장소의 `claude/keen-lovelace-joi9xc` 브랜치에서 새 브랜치 `gemini/models`를 만든다. 이 문서와 검사 도구가 그 브랜치에 있다.
2. 새로 만든 것만 커밋한다:
   - `assets/characters/gemini/*.glb`
   - `assets/gear/gemini/*.glb`
   - (가구를 만들었다면) `assets/props/gemini/*.glb`
   - `tools/models/gemini/*`
   - Godot가 만드는 `*.import`와 추출된 텍스처는 `.gitignore`가 거른다.
3. `git push -u origin gemini/models`
4. 사람에게 끝났다고 알린다.

## 7. 되돌리기

- 파일 하나만 빼려면 `gemini` 폴더에서 그 파일을 지운다.
