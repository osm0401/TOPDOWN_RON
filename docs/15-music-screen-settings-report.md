# 긴장감 배경음, 화면 반응, 설정 메뉴 결과

목록의 23, 25, 26번이에요. 수치는 모두 임시값이고 `data/audio.json`의 `music`·`breath`, `data/view3d.json`의 `screen_fx`에 있어요.

## 1. 긴장감 배경음 (23)
- 코드로 만든 8초짜리 반복 음악 4층을 동시에 틀어요. 파일은 받지 않아요.
  - `drone` 낮은 울림: 임무 중 항상
  - `pulse` 낮은 베이스 반복: 적이 수상해하거나 총소리가 났을 때
  - `drums` 북과 하이햇: 교전 중
  - `strings` 높고 떨리는 현: 맞았을 때, 가장 위험할 때
- 긴장도(0~1)에 따라 층이 하나씩 커져요.
  - 총소리, 피격: 바로 올라가고 6초(`hold_s`) 유지, 그 뒤 천천히 내려감(`fall_per_s`)
  - 근처(900 px) 적이 나를 찾는 중·발견·교전 중이면 그 수준 아래로는 안 내려가요
- 브리핑에는 낮은 울림만 작게, 결과 화면에서는 모두 잦아들어요.
- `assets/audio/music_<층>_0.wav`를 넣으면 그 층은 파일을 써요(나중에 실제 음악으로 교체할 때).
- 음악은 로비에 있는 동안 백그라운드에서 만들어요. 다 되기 전에 임무를 시작하면 준비되는 대로 들어와요.

## 2. 화면 반응 (25)
- 쏠 때 화면이 흔들려요(소총이 권총보다 조금 크게). 맞을 때 더 크게, 바로 옆 총소리·문 차기에도 살짝.
- 맞으면 화면 가장자리가 붉게 번쩍해요(0.6초).
- 체력이 절반 아래면 가장자리가 붉게 남고 색이 바래며, 심장 박동처럼 깜빡여요. 낮을수록 빨라요.
- 체력 60% 아래면 거친 숨소리, 맞은 직후에는 숨을 헐떡이는 소리가 나요(기존 심장 소리와 함께).
- 머리 위 `HP 3/5` 글씨를 없앴어요(2D 화면의 체력 막대도). 락픽·구속 진행률은 그대로 보여요. 내 체력은 왼쪽 위 글에 남아 있어요.

## 3. 설정 메뉴 (26)
- 로비의 "설정" 버튼, 임무 중 Esc → "설정".
- Esc는 이제 바로 나가지 않고 메뉴(계속하기 / 설정 / 임무 나가기)를 열어요. 메뉴가 열린 동안 내 경찰은 멈춰 있어요(게임 자체는 상대와 공유라 계속 진행).
- 소리: 전체 음량, 효과음, 배경음
- 그래픽: 품질(높음/보통/낮음, F8과 같음), 전체 화면, 수직 동기화, 최대 FPS, 3D 해상도(50~100%, 낮추면 빨라짐), 화면 흔들림 세기(0이면 끔)
- 조작: 마우스 감도, 키 바꾸기 17개
  - 버튼을 누르고 새 키를 누르면 바뀌어요. Esc는 취소.
  - 다른 동작이 쓰던 키면 두 동작의 키를 서로 바꾸고 알려줘요.
  - Esc와 F1~F12는 바꿀 수 없어요. 사격은 왼쪽 클릭 고정.
  - 화면 위 조작 안내와 브리핑·결과 화면 안내도 바뀐 키로 보여요.
- 마우스 감도
  - 1.0이면 윈도우 커서 그대로(예전과 같음).
  - 다른 값이면 임무 중에는 커서를 숨기고 조준점(+)을 그려서, 마우스를 움직인 만큼 × 감도로 움직여요.
  - 브리핑, 결과 화면, 메뉴에서는 보통 커서로 돌아와요(버튼을 눌러야 하니까).
- 저장 위치: `user://settings.cfg` (윈도우: `%APPDATA%\Godot\app_userdata\TOPDOWNRON\settings.cfg`). 바꾸는 즉시 적용, 닫을 때 저장.

- 테스트는 플레이어의 설정 파일 대신 별도 파일을 써요.
- 화면 캡처로 설정 3개 탭, 일시정지 메뉴, 체력 낮을 때 붉은 화면을 확인했어요.
