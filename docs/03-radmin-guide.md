# Radmin VPN으로 친구와 테스트 (사용자 직접 수행)

게임은 방을 만들 때 이 PC의 VPN 주소를 자동으로 찾습니다. 우선순위: Tailscale(100.64~127.x) > Radmin(26.x) > Hamachi(25.x) > UPnP > 로컬 전용.

## 1. 두 PC 모두
1. Radmin VPN 설치 (공식 사이트에서 받기). 계정은 필요 없음.
2. **한 사람이** 네트워크를 만듭니다: 이름과 비밀번호 입력.
3. **다른 사람이** 그 네트워크에 가입합니다: 같은 이름과 비밀번호 입력.
4. 각자 Radmin 창에서 상대 이름이 초록색(연결됨)인지 확인. 상대 이름을 우클릭해 IP를 복사하거나 핑을 보낼 수 있습니다. (메뉴 이름은 버전에 따라 다를 수 있음)
5. 내 Radmin 주소는 `26.x.x.x` 형태입니다. 터미널에서 `ipconfig`로도 확인할 수 있습니다.

## 2. 게임 (둘 다 Godot 4.7.2 + 이 저장소 필요)
1. 방장: "방 만들기" → 화면에 `XXXX-XXXX-XXXX` 코드와 "VPN 주소 사용: radmin"이 표시됨.
2. 방장이 Windows 방화벽 허용 창을 받으면 허용 (Radmin 어댑터가 "공용"이면 공용도 체크).
3. 친구: 코드 입력 → "코드로 참가".

## 3. 안 될 때
- 방장 화면에 "VPN 주소 사용" 대신 UPnP/로컬 안내가 나오면: Radmin이 꺼져 있거나 연결 전. Radmin이 `26.x` 주소를 받은 뒤 방을 다시 만드세요.
- 친구 화면에 "연결 시간이 초과되었습니다": 방화벽 허용 여부, 두 PC가 같은 Radmin 네트워크에 있는지 확인. 방장에게 핑(`ping 26.x.x.x`)이 가는지 확인.
- 로그: `%APPDATA%\Godot\app_userdata\TOPDOWNRON\net_log_host.txt`, `net_log_client.txt`
