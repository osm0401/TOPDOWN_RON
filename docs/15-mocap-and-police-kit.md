# 모션 캡처 동작, 경찰 장구, 새 인물

목록의 10번(새 인물), 11번(모션 캡처 동작), 12번(경찰 장비 디테일) 결과예요.

## 1. 모션 캡처 동작 (11번)

게임이 실제 사람이 움직인 동작 파일을 읽어서 모든 인물(경찰, 용의자, 민간인, 앞으로 만들 새 인물)에 입혀요. 파일이 없으면 지금처럼 코드 동작을 써요.

- 코드: `src/game/motion_clips.gd`(파일 읽기, 변환), `src/game/character_anim.gd`(언제 어디에 입힐지)
- 파일 자리: `assets/anim/` (`walk`, `run`, `idle`, `hands_up`, `reload`. 이름과 쓰임은 그 폴더의 README)
- 어떤 몸에도 맞아요: 팔다리는 "방향", 허리·가슴·머리·발은 "기운 정도"로 바꿔 입혀서 키, 체형, 처음 자세(A자, T자)가 달라도 돼요.
- 파일이 누워 있거나(Z 위쪽) 다른 쪽을 봐도 처음 자세의 어깨와 머리로 앞을 찾아서 바로 세워요.
- 뼈 이름은 Mixamo(`mixamorig:LeftUpLeg`), Meshy·Higgsfield(`LeftUpLeg`), Godot 사람 뼈(`LeftUpperLeg`), `thigh_l` 같은 이름을 다 알아봐요.
- 걷기·달리기는 게임 보폭에 맞춰 재생해서 발이 미끄러지지 않아요. 뒤로 걸으면 거꾸로 재생하고, 옆으로 걸을 때는 코드 동작을 써요(앞으로 걷는 동작을 옆으로 돌리면 무릎이 이상하게 굽어서).
- 총을 겨눈 팔은 지금처럼 손이 총을 잡게 계산해요. 동작 파일은 다리, 허리, 빈손인 팔, 머리에 쓰여요. 항복할 때는 두 팔과 가슴, 재장전할 때는 왼팔에 써요.
- 값: `data/view3d.json` `characters.clips` (켜고 끄기, 세기, 재생 속도, 파일 하나에 동작이 여럿일 때 고를 이름)

### 동작 파일 받는 방법

**A. 무료: Mixamo (PC에서 직접, 계정 필요)**

1. https://www.mixamo.com 에 Adobe 계정(무료)으로 로그인
2. 위의 Animations에서 검색해 고르기. 오른쪽에 "In Place"가 있으면 켜기

   | 저장할 이름 | 검색어 (예) |
   |---|---|
   | `walk.fbx` | Walking |
   | `run.fbx` | Running |
   | `idle.fbx` | Breathing Idle |
   | `hands_up.fbx` | Surrender (없으면 Hands Up) |
   | `reload.fbx` | Reloading |
   | (선택) `walk_officer.fbx` | Rifle Walk (경찰만 다르게) |

3. Download: Format **FBX Binary**, Skin **Without Skin**, Frames per Second **30**
4. 받은 파일 이름을 위 표대로 바꿔 `assets/anim/`에 넣기. 게임을 켜면 바로 써요
5. 확인: 콘솔에 `[clips] walk.fbx: 1.03 s, 32 frames`처럼 나와요

라이선스: Mixamo 동작은 게임에 넣어 배포해도 돼요(Adobe 약관상 동작 파일만 따로 다시 배포하는 것은 안 됨). 공개 저장소에 올리기 전에 약관을 한 번 확인하세요.

**B. Higgsfield 크레딧 (Claude가 대신 만듦)**

Higgsfield의 "3D Rigging"으로 우리 경찰 모델에 동작 라이브러리(678개, 모션 캡처)를 입힌 파일을 받아요. **동작 하나에 8 크레딧**이고, 지금 잔액은 0.5라서 못 해요.

| 칸 | 추천 동작 (번호) | 크레딧 |
|---|---|---|
| walk | Casual_Walk (30) | 8 |
| run | RunFast (16) | 8 |
| idle | Idle (0) | 8 |
| reload | Standing_Reload (170) | 8 |
| 합계 | | **32** |

항복(손 들기) 동작은 라이브러리에 없어서 A(Mixamo)로 받는 게 좋아요. 크레딧을 채우면 Claude에게 "모션 캡처 동작 만들어 줘"라고 하면 돼요.

### 시험한 것
- 무료 공개 샘플(three.js 예제의 Mixamo 로봇 걷기·달리기·서 있기)을 넣어 그림으로 확인: 경찰·민간인·용의자 모두 걷기, 달리면서 소총 겨누기, 정면·뒤로 걷기. 샘플 파일은 저장소에 넣지 않았어요.
- 자동 테스트: 누워 있는(Z 위쪽, -Y 앞) 시험용 뼈대를 만들어 바로 세워지는지, 왼발이 가장 앞에 나오는 때를 찾는지, .glb로 저장했다 다시 읽어도 같은지, 이름으로 동작을 고르는지, 보폭 위상에 맞는지, 파일이 없으면 코드 동작 그대로인지.

## 2. 경찰 장구 (12번)

- **헬멧 카메라**: 헬멧 오른쪽 레일에, 렌즈는 앞으로. 빨간 녹화 불빛이 1초마다 깜빡여요.
- **무전기 불빛**: 가슴 무전기(이미 있던 것)에 화면, 채널 손잡이, 클립을 더 달고 위에 불빛을 넣었어요. 평소에는 2초마다 초록으로 짧게 깜빡이고, 경찰이 말하면(명령, 보고) 1.5초 동안 빨강이에요. 두 경찰은 깜빡이는 때가 달라요.
- **어깨 무전 마이크**: 조끼 왼쪽 어깨끈에, 무전기로 가는 줄까지.
- 모두 모델 모양(머리 크기, 가슴 앞면)을 재서 붙여서 새 경찰 모델에도 맞아요.
- **장갑**: 지금 경찰 모델에 이미 검은 장갑이 있어서 따로 붙이지 않았어요. 새 경찰 모델 안내(`docs/09` 2.)에도 "검은 장갑"이 들어 있어요.
- 값: `data/view3d.json` `characters.police_kit` (켜고 끄기, 깜빡이는 간격, 말한 뒤 빨강 시간)
- 장구 모양도 파일로 바꿀 수 있어요: `assets/gear/<세트>/helmet_cam.glb`, `radio.glb`, `mic.glb` (불빛 자리는 빈 노드 `led`). 검사 도구는 없어도 경고하지 않아요.

## 3. 새 인물 (10번)

코드 준비는 이전 작업(캐릭터 업그레이드, `docs/13`)에서 끝나 있어요. `enemy_2.glb`~`enemy_9.glb`, `civilian_2.glb`~`civilian_9.glb`를 넣으면 게임이 사람마다 골라 쓰고, 이번 모션 캡처 동작도 그대로 입혀요. 남은 것은 모델 파일 만들기예요.

- **PC (무료, 추천)**: Antigravity에 `docs/09-3d-models-antigravity.md` 맨 아래 "인물 종류만 더 만들 때" 문장을 그대로 붙여 넣기. 여자(`civilian_2`), 노인(`civilian_3`), 회사원(`civilian_4`)과 적 3명이 표에 있어요. 끝나면 Claude에게 알려 주세요. 받아서 게임 안에서 확인하고 합칠게요.
- **Higgsfield 크레딧**: 인물 하나에 정면·옆·뒤 그림 3장(0.15 × 3 = 0.45) + 3D 변환. 3D는 `sam_3_3d` 1 크레딧(빠르지만 거칠음)부터 여러 장으로 만드는 `multi_image_to_3d` 30 크레딧(사진 질감, 더 정확)까지예요. 6명을 좋은 품질로 하면 약 183 크레딧, 거친 품질로 하면 약 9 크레딧이에요.

## 검증 (이 환경, Godot 4.7.2 리눅스)
- 단위 테스트, 통합 테스트 모두 통과 (새 시험: 동작 파일 13개, 경찰 장구 2개)
- 모델 검사 도구 FAIL 0개
- 그림 확인: 동작 입힌 걷기·달리기·서 있기, 장구 단 경찰 다섯 방향, 장비 그림(장구 3개 추가)

## 미검증 / 한계
- 실제 Mixamo, Higgsfield 파일로는 아직 시험하지 못했어요(크레딧 부족, Mixamo는 로그인이 필요). 같은 Mixamo 뼈대 샘플로는 시험했어요.
- 손가락은 움직이지 않아요(우리 뼈대에 손가락이 없음).
- 재장전 동작은 다른 총으로 찍은 것이라 왼손이 탄창에 딱 맞지 않을 수 있어요. 이상하면 `clips.reload.on`을 false로 하세요.
- 게임 창(Windows)에서 직접 걸어 다니며 보지는 못했어요.
