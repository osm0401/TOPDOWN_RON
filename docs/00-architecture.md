## 2. 권한 표 (호스트 권한형, 승인됨)

| 상태 | 결정 주체 | 클라 → 호스트 | 호스트 → 클라 |
|---|---|---|---|
| 플레이어 이동/방향 | 호스트가 검증·확정 | 입력(이동벡터, 조준각) | 확정 위치/방향/사망 |
| 발사/명령/상호작용 | 호스트 | 입력 이벤트 | 결과 이벤트 |
| 문 상태(열림/잠김) | 호스트 | 행동 요청 | 확정 상태 |
| 탄약/장비 | 호스트 | 재장전 요청 | 잔탄/예비 탄창 |
| 적/민간인 상태·위치 | 호스트 (AI는 호스트에서만 실행) | — | 상태, 위치, 무장/구속 |
| 소리 이벤트 | 호스트 | — | 방향성 재생용 이벤트 |
| 레이저/손전등 | 호스트 | on/off 요청 | on/off + 조준각 |
| 목표/점수/증원/결과 | 호스트 | — | 전체 |
| 결과 투표 | 호스트 집계 | 선택 | 집계/재투표 |

규칙
- 클라 입력값은 신뢰하지 않음: 이동 속도 상한, 발사 간격, 사거리/탄약을 호스트가 검증.
- RPC는 `@rpc("any_peer"|"authority", "call_remote", "reliable"|"unreliable")`을 항상 명시.
- 이동은 클라 예측 없이 시작 → 지연이 거슬리면 클라 측 자기 이동 예측만 추가 (불일치 판정 후).
- 최대 2명: 세 번째 피어는 `peer_connected`에서 즉시 `disconnect_peer`.
- 끊김: 감지 → 알림 → 로비 복귀. 재접속/호스트 이전 없음.

## 3. 방 코드 (제안, 승인 필요)

- 페이로드: IPv4 4바이트 + 포트 2바이트 + 체크섬 1바이트 = 7바이트 = 56비트.
- Crockford Base32(0/O, 1/I/L 혼동 없음) 12글자 → 표시 `XXXX-XXXX-XXXX`. 입력 시 대소문자·하이픈 무시.
- 체크섬(XOR 또는 CRC8)으로 오타 즉시 검출.
- 방이 열려 있는 동안만 유효: 호스트가 listen 중지하면 접속 실패. 서버 없음.
- 주의: 코드 = 주소. Tailscale 안(100.x)에서만 접근되므로 노출 위험은 같은 tailnet 사용자에 한정.
- 로컬 테스트: `127.0.0.1` 코드도 허용 (한 PC에서 인스턴스 2개).
- 호스트가 자기 IP를 아는 법: Tailscale이 있으면 `100.x` 주소를 자동 선택(네트워크 인터페이스 중 100.64.0.0/10), 없으면 로컬 주소 목록에서 선택하게 함.

## 4. 단계 1 범위
방 생성 → 코드 표시 → 코드 입력 참가 → 두 플레이어 위치/방향 동기화 → 문 1개 → 적 상태/점수 샘플 → 지연·끊김 로그.
