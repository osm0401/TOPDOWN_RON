# 단계 3 결과 — 협동 진입과 정보 전달

## 구현 범위
- 문: 닫힘 / 약간 열림(12px 틈) / 열림 + 잠금. 일반 열기, 약간 열기, 발로 차기, 락픽. 마지막 조작자 색 표시
- 문틈 카메라: 문 반대편 시점. 사용 중 이동 불가
- 조명: 방별 밝음/어두움. 손전등 빔(시야 가림 반영), 어두운 방에서는 빔 밖은 윤곽만
- 레이저: 양쪽 플레이어 화면에 표시, 적이 빔이 닿은 점을 보면 그쪽을 바라봄
- 소리: 총성, 발소리, 문(일반/약간/걷어차기), 목소리, 비명, 테이저. 벽/문 감쇠(닫힌 문이 벽보다 큼)
- 적 AI (경계 전, 소리 확인, 발견, 위협, 공격, 항복, 도주, 숨음, 기절, 구속, 사망): 경로 탐색, 문 열고 이동,
  동료 경고 공유(거리+벽 제한), 항복하는 척 후 공격(겨눔 신호 포함)
- 민간인 AI: 총성에 숨거나 도망, 비명(적에게 소리로 전달), 명령에 복종/거부
- 명령 4종(대사 무작위), 위협 사격, 테이저, 비살상 소총 기절, 구속(E 길게)
- 플레이어 체력/사망, 난이도 선택(쉬움/보통/어려움)
- 디버그 표시: NPC 상태와 이유(F4), 소리 파문(F3)

## 구조
| 파일 | 역할 |
|---|---|
| `src/core/npc_brain.gd` | NPC 상태 기계 (순수 로직, 전이 설명 주석 포함) |
| `src/core/sound_prop.gd`, `light_model.gd`, `geom2d.gd` | 소리 전파, 조명 식별, 기하 계산 (순수) |
| `src/game/npc_director.gd` | 호스트 NPC 시뮬레이션: 지각, 이동, 사격, 명령, 구속, 패킹 |
| `src/game/level.gd` | 맵, 문 상태, 광선, 가시 영역, 소리 차단 계산, 경로 격자 |
| `src/game/net_world.gd` | 호스트 권한 시뮬레이션과 동기화 |
| `src/game/world_view.gd` | 그리기/HUD |
| `data/*.json` | 맵, 튜닝, 난이도, 명령 대사, 임시 장비 |

## 검증 (이 PC)
- 단위 테스트 150개: 기하, 소리 전파, 조명, NPC 상태 기계 전이, 문/잠금/경로, 감독기(소리 듣기, 시야, 어둠, 경고 공유, 명령, 구속, 사격)
- 통합 테스트 27개 (`tests/world_test.tscn`): 락픽, 발로 차기, 약간 열기, 문틈 카메라, 명령 후 구속, 테이저 후 구속, 무기 교체, 피격/사망
- 두 프로세스 시험: 호스트/클라이언트 최종 상태 일치 (localhost 3회, Radmin 주소 1회, 창 모드 1회)
- 창 모드 스크린샷: 안개, 손전등 빔, 레이저, 소리 파문, 열린 문

## 미검증 / 한계
- 사람이 직접 한 플레이 감각, 난이도/확률 수치의 균형 (모두 임시값)
- 실제 두 PC 사이의 네트워크
- NPC 모습(위협 표시, 항복 자세)을 스크린샷으로 확인하지는 못함 (헤드리스/로직 테스트만)
- 장비 선택 화면 없음 (고정 장비), 창문 없음, 오디오 없음, 사망자 관전 없음
- 적은 엄폐물을 쓰지 않고 도주 목적지만 고름. 민간인 구속 목표/점수는 단계 4
