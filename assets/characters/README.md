# assets/characters

3D 화면(F5)의 인물 모델입니다. 파일이 없으면 지금처럼 도형(캡슐과 공) 인물이 그대로 나오고, 2D 화면은 바뀌지 않습니다.

| 파일 | 누구 | 언제 |
|---|---|---|
| `officer.glb` | 경찰(두 플레이어) | 항상. 두 사람은 윤곽에 비치는 파랑/주황 빛으로 구분 |
| `enemy.glb` | 용의자(무장 적, 미끼, 지정 용의자 모두) | 항상: 서기·걷기, 항복(손을 머리 위로), 엎드림(엎드려 손을 머리 뒤로), 숨음(웅크려 머리 감싸기), 구속(무릎 꿇고 뒤로 수갑), 사망(누움) |
| `civilian.glb` | 민간인 | 용의자와 같음 |
| `enemy_up.glb` / `civilian_up.glb` | 손 든 자세 모델 | 지금은 쓰지 않음. `data/view3d.json`의 `characters.surrender_model`을 true로 하면 항복할 때 서 있는 모델 대신 이 모델이 나옴 |

## 모델 묶음과 만드는 사람

**앞으로 3D 모델(인물, 장비)은 Antigravity(Gemini)가 만듭니다.** 작업 안내와 규칙: `docs/09-3d-models-antigravity.md`. 다 만든 모델은 검사 도구 `tools/models/check_models.gd`로 확인합니다.

- 새 모델은 묶음 폴더에 들어갑니다: `assets/characters/gemini/`(인물), `assets/gear/gemini/`(장비). 이 폴더의 파일은 기존 파일(이 폴더의 `*.glb`, 장비는 코드로 만든 모양)을 지우지 않고 대신 쓰입니다.
- 어느 묶음을 먼저 쓸지는 `data/view3d.json`의 `characters.set`에서 정합니다(지금 `"gemini"`). 묶음에 없는 파일은 기존 것을 씁니다. `""`이면 기존 것만 씁니다.

- 모델에는 **무기, 모자, 완장을 넣지 않습니다**. 총(무장 여부), 빨간 모자와 노란 완장(지정 용의자 단서)은 게임 규칙에 쓰여서 게임이 따로 붙입니다.
- 크기, 위치, 방향은 게임이 맞춥니다(`src/game/character_models.gd`). 키는 `height_m`(손 든 모델은 손끝까지 `up_height_m`)으로 맞추고 바닥에 세웁니다. 모델이 다른 쪽을 보고 있으면 `data/view3d.json`의 `characters.yaw_deg`를 바꾸세요(glTF 기본인 +Z 정면이면 90).
- 에디터를 열지 않아도 파일을 넣기만 하면 읽습니다(가져오기를 했으면 가져온 장면을 씁니다).
- 맞았을 때 흰색 번쩍임, 사망 회색, 엎드림·구속 어둡게는 모델 위에 반투명 색을 덧칠해 표현합니다.

## 뼈대

모델에는 뼈대가 없어도 됩니다. 게임이 불러올 때 모양을 보고 뼈대 14개를 붙입니다(`src/game/character_models.gd`의 `_rig`).
- 엉덩이, 허리, 가슴, 머리 / 허벅지, 정강이, 발 (양쪽) / 위팔, 아래팔 (양쪽)
- 다리: 두 다리 사이 틈으로 좌우를 나누고, 엉덩이·무릎·발목·가슴·목·팔꿈치 높이는 사람 비율(키의 약 0.5, 0.27, 0.05, 0.71, 0.86, 0.62)에 맞춥니다.
- 팔: 손목에서 메시가 이어진 부분을 따라 올라가며 찾습니다. 팔이 몸과 떨어져 있으면 겨드랑이 가까이까지, 몸통에 붙어 있으면 팔꿈치 아래까지만 따라가고 그 위는 몸 바깥선으로 나눕니다. 손이 허벅지에 붙어 생성된 경우에는 그 사이 면을 끊어서 손이 떨어질 때 살이 늘어나지 않게 합니다.
- 손 든 모델(`*_up`, `surrender_model`이 true일 때만 씀)은 팔을 몸의 일부로 두고 다리, 허리, 머리만 움직입니다.
- 생성 모델에 면 방향(노멀)이 없어서 조명이 고르게만 비쳤는데, 뼈대를 붙일 때 노멀을 계산해 넣습니다.
- 파일에 뼈대가 이미 있어도(예: 리깅 도구를 거친 파일) 버리고 모양으로 다시 붙입니다. 게임 자세는 이 뼈대 14개만 압니다.

## 움직임과 자세

`src/game/character_anim.gd`가 매 프레임 상태에 맞춰 뼈를 돌립니다. 팔은 잡을 곳(총 손잡이, 총 앞손잡이, 머리 뒤 등)에 손이 닿도록 관절 각도를 거꾸로 계산(IK)해서, 다른 기본자세(A자, T자)로 만든 모델도 같은 자세가 나옵니다.
- 걷기·달리기: 화면에서 움직인 거리로 보폭을 맞추고, 빠를수록 보폭·무릎·팔꿈치를 더 굽힙니다. 옆걸음·뒷걸음도 그 방향으로 딛습니다.
- 경찰: 소총은 어깨에 대고 두 손으로(왼쪽 어깨를 앞으로 틀어 겨눔), 권총은 두 팔을 뻗어 겨눕니다. 쓰지 않는 총은 등(소총)이나 오른쪽 허벅지(권총)에. 재장전 때 총을 기울이고 왼손이 탄창으로 갔다 옵니다. 문따기·구속·문틈 카메라 때는 한쪽 무릎을 꿇고 손을 앞으로(소총은 앞에 늘어뜨림, 카메라는 손에).
- 용의자·민간인: 항복하면 서 있는 모델이 그대로 두 손을 머리 위로 들어 올립니다(얼굴과 옷이 그대로, 손바닥이 앞을 보게 아래팔을 비틂). 무장한 적은 권총을 내려 들고 다니다가 위협·공격 때 한 손으로 겨눕니다. 발견 단계에는 경찰 쪽으로 고개를 돌리고, 맨손이면 손을 가슴 앞으로 올립니다. 평소에는 두리번거리고, 수색 중에는 더 크게 둘러봅니다.
- 그 밖: 숨쉬기, 서 있을 때 무게 이동, 맞으면 움찔, 쏘면 반동과 총구 불꽃, 쓰러지는 동작, 자세가 바뀔 때 0.25초에 걸쳐 넘어감.
- 장비(`src/game/gear_models.gd`, 상자·원기둥으로 만든 모양): 실탄 소총(검정, 조준경·라이트), 비살상 소총(주황), 권총(라이트), 수갑, 빨간 모자(머리에), 노란 완장(왼팔에), 문틈 카메라, 바닥에 떨어진 권총(노랗게 빛남). 손전등 빛과 레이저, 총알 궤적은 총에서 나옵니다.

값은 `data/view3d.json`의 `characters.walk`(걸음)와 `characters.pose`(숨쉬기, 움찔, 반동, 넘어가는 시간 등)에서 바꿉니다. 마우스 휠로 카메라를 가까이 당기면 자세히 보입니다(`camera.zoom_min`~`zoom_max`).

더 정밀한 모델로 바꿀 때는 파일만 같은 이름으로 넣으면 됩니다. 팔을 몸에서 떼고(A자 자세) 손이 몸에 닿지 않게 만든 모델일수록 팔을 들 때 옷이 덜 늘어납니다.

## 출처

다섯 모델 모두 2026-10-11 사용자 계정의 Higgsfield에서 만들었습니다.
- 그림: `z_image`(9:16)로 "몸 전체, 정면, 팔을 몸에서 살짝 뗀 자세, 빈손, 무기·모자·완장 없음, 밝은 회색 배경" 조건을 붙여 생성
- 3D: 각 그림을 `sam_3_3d`(SAM 3 3D Objects, 텍스처 포함)로 변환. 모델당 면 4.7천~7.1천 개, 텍스처 1024×1024
- 게임용 손질: 재질의 금속도를 0, 거칠기 0.85로 고침(생성기가 glTF 기본값 금속도 1.0을 남겨 옷과 피부가 금속처럼 어둡게 보였음). 텍스처를 JPEG(품질 90)로 다시 저장. 모양과 텍스처 좌표는 그대로(파일당 1.3 MB → 0.3 MB)
- 정면은 +Z(glTF 기본)라 `yaw_deg` 90 그대로. 손 든 모델은 손이 머리 위로 높지 않아 `up_height_m` 1.9로 맞춰야 서 있는 모델과 몸 크기가 같음
- `officer.glb`, `enemy.glb`, `civilian.glb`는 같은 날 다시 만들었습니다: 팔을 몸에서 뗀 자세(A자)로 그린 `source/`의 그림을 `sam_3_3d`로 변환(면 약 4.1천~5.3천 개). 팔이 몸통과 떨어져 있어서 총을 겨누거나 머리를 감쌀 때 겨드랑이 아래 옷이 늘어나지 않습니다. 손 든 모델(`*_up`)은 처음 만든 것 그대로입니다(`source/`의 손 든 그림으로 다시 만들 수 있음).
