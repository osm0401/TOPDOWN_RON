# 3D 화면 시험판 결과 — 비스듬한 3D 카메라 (도형 임시 표현)

## 목적
2D 회색 상자 화면과 비스듬한 3D 화면을 같은 게임 상태로 나란히 비교해, 에셋을 입히기 전에 방향을 정한다.

## 쓰는 법
- 게임 중 `F5`: 2D <-> 3D 전환 (HUD, 브리핑, 결과 화면은 그대로 2D)
- 기본은 3D로 시작(`data/view3d.json`의 `start_3d`). 2D로 시작: 실행 인자 `-- --view2d` (예: `Godot.exe --path D:/TOPDOWNRON -- --solo --view2d`), `-- --view3d`는 3D로 시작
- 값 조정: `data/view3d.json` (카메라 각도/거리/시야각, 벽 높이, 벽 낮춤, 조준 높이) — 모두 임시값

## 구조
| 파일 | 역할 |
|---|---|
| `src/game/world_view_3d.gd` | 3D 화면 (도형만 사용). 시뮬레이션 상태를 읽기만 함 |
| `src/game/world_view.gd` | F5 전환. 시야 다각형/손전등/NPC 보임 계산은 계속 여기서 하고 3D가 그 결과를 재사용 |
| `src/game/net_world.gd` | `mouse_world` 훅 하나만 추가: 3D가 커서의 지면 좌표를 넘겨주면 기존 조준 계산이 그대로 동작 |
| `data/view3d.json` | 3D 설정값 |

규칙, AI, 네트워크, 점수, 데이터 파일은 바뀌지 않았다 (3D로 켠 실행과 2D 실행의 최종 상태가 동일).

## 구현된 표현
- 바닥, 어두운 방, 탈출 구역, 벽(상자), 문(상태/색/잠금 표시)
- 시야 안개: 시야 다각형 밖은 바닥 안개, 다각형에 닿지 않는 벽/문은 숨김
- 플레이어/NPC (캡슐+머리): 서기, 엎드림(쓰러짐), 구속(웅크림+수갑), 항복(손 든 모습), 숨음(웅크림), 사망(누움)
- 인물 모델(`assets/characters/`, 있으면 캡슐 대신): 불러올 때 뼈대를 자동으로 붙여 걷는다(`src/game/character_models.gd`). 화면에서 움직인 거리로 보폭을 맞추고, 빠를수록 보폭과 무릎 굽힘이 커진다. 옆걸음, 뒷걸음도 그 방향으로 발을 딛는다. 값: `data/view3d.json`의 `characters.walk`
- 단서: 붉은 모자(머리 위 원통), 노란 완장(몸 옆 상자), 떨어진 무기
- 손전등 원뿔, 레이저, 총탄 궤적, 소리 파문, 말풍선, 행동 진행률, 상태 표시(? ! !!)
- 문틈 카메라 위치 표시

## 검증 (이 PC)
- 단위 테스트 226개, 통합 테스트(3D 11개 추가) 전부 통과
- 3D 커서 -> 지면 좌표 변환, 조준 훅 설치/해제, 안개 메쉬, 시야 판정, 벽 낮춤
- 창 모드 스크린샷: 단서 장면, 기본 협동 장면 (2D 대비 같은 상태)
- 두 프로세스 스모크 통과, 3D 실행과 최종 상태 동일

## 미검증 / 한계
- 사람이 직접 한 조작감 (3D 조준이 2D만큼 정확한지), 수치 모두 임시
- 벽 옆면 안개 처리 없음 (일부만 보이는 벽은 통째로 보임), 그림자/실제 손전등 광원 없음
- 벽 가림은 "플레이어 바로 남쪽 벽 낮춤"만 처리. 다른 위치의 가림(예: 문 너머 방 안쪽)은 카메라 각도에 따라 남음
- 애니메이션은 걷기뿐(자동 뼈대: 엉덩이, 허리, 허벅지, 정강이, 팔). 팔꿈치, 손목, 고개는 굽지 않고, 총을 든 자세나 달리기 전용 동작도 없다. 생성 모델에서 손이 허벅지에 붙어 있던 자리는 팔을 흔들 때 살짝 늘어난다
