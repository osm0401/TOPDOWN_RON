# assets/characters

3D 화면(F5)의 인물 모델입니다. 파일이 없으면 지금처럼 도형(캡슐과 공) 인물이 그대로 나오고, 2D 화면은 바뀌지 않습니다.

| 파일 | 누구 | 언제 |
|---|---|---|
| `officer.glb` | 경찰(두 플레이어) | 항상. 두 사람은 파랑/주황 색을 살짝 덧칠해 구분 |
| `enemy.glb` | 용의자(무장 적, 미끼, 지정 용의자 모두) | 서 있을 때, 엎드림·사망(눕힘), 숨음·구속(웅크림) |
| `enemy_up.glb` | 용의자, 손 든 자세 | 항복했을 때 (없으면 서 있는 모델에 도형 팔을 붙임) |
| `civilian.glb` | 민간인 | 용의자와 같음 |
| `civilian_up.glb` | 민간인, 손 든 자세 | 항복했을 때 |

- 모델에는 **무기, 모자, 완장을 넣지 않습니다**. 총(무장 여부), 빨간 모자와 노란 완장(지정 용의자 단서)은 게임 규칙에 쓰여서 게임이 따로 붙입니다.
- 크기, 위치, 방향은 게임이 맞춥니다(`src/game/character_models.gd`). 키는 `height_m`(손 든 모델은 손끝까지 `up_height_m`)으로 맞추고 바닥에 세웁니다. 모델이 다른 쪽을 보고 있으면 `data/view3d.json`의 `characters.yaw_deg`를 바꾸세요(glTF 기본인 +Z 정면이면 90).
- 에디터를 열지 않아도 파일을 넣기만 하면 읽습니다(가져오기를 했으면 가져온 장면을 씁니다).
- 맞았을 때 흰색 번쩍임, 사망 회색, 엎드림·구속 어둡게는 모델 위에 반투명 색을 덧칠해 표현합니다.

## 걷기

모델에는 뼈대가 없어도 됩니다. 게임이 불러올 때 모양을 보고 뼈대를 붙입니다(`src/game/character_models.gd`의 `_rig`).
- 다리: 두 다리 사이 틈으로 좌우를 나누고, 엉덩이·무릎 높이는 사람 비율(키의 약 0.5, 0.27)에 맞춥니다.
- 팔: 어깨에서 몸 바깥선을 따라 내려가고, 팔뚝과 손은 손목에서 메시가 이어진 부분을 따라 찾습니다. 손이 허벅지에 붙어 생성된 경우에는 허벅지 바깥선에서 끊습니다. 끊은 곳은 몇 cm에 걸쳐 가중치를 섞어 뾰족하게 찢어지지 않게 하고, 그런 모델은 팔을 덜 흔듭니다(`characters.walk.fused_arm`, 지금 다섯 모델 중 officer, enemy, civilian의 왼손이 해당).
- 손 든 모델(`*_up`)은 다리만 움직입니다.
- 생성 모델에 면 방향(노멀)이 없어서 조명이 고르게만 비쳤는데, 뼈대를 붙일 때 노멀을 계산해 넣습니다.
- 뼈대가 이미 있는 모델(예: 리깅 도구를 거친 파일)은 손대지 않고, 그 모델은 걷지 않습니다.

걸음 빠르기, 보폭, 각도는 `data/view3d.json`의 `characters.walk`에서 바꿉니다.

## 출처

다섯 모델 모두 2026-10-11 사용자 계정의 Higgsfield에서 만들었습니다.
- 그림: `z_image`(9:16)로 "몸 전체, 정면, 팔을 몸에서 살짝 뗀 자세, 빈손, 무기·모자·완장 없음, 밝은 회색 배경" 조건을 붙여 생성
- 3D: 각 그림을 `sam_3_3d`(SAM 3 3D Objects, 텍스처 포함)로 변환. 모델당 면 4.7천~7.1천 개, 텍스처 1024×1024
- 게임용 손질: 재질의 금속도를 0, 거칠기 0.85로 고침(생성기가 glTF 기본값 금속도 1.0을 남겨 옷과 피부가 금속처럼 어둡게 보였음). 텍스처를 JPEG(품질 90)로 다시 저장. 모양과 텍스처 좌표는 그대로(파일당 1.3 MB → 0.3 MB)
- 정면은 +Z(glTF 기본)라 `yaw_deg` 90 그대로. 손 든 모델은 손이 머리 위로 높지 않아 `up_height_m` 1.9로 맞춰야 서 있는 모델과 몸 크기가 같음

| 파일 | 그림 내용 |
|---|---|
| `officer.glb` | 검은 헬멧, 남색 제복, 검은 방탄조끼와 장갑, 무릎 보호대 |
| `enemy.glb` | 빨간 후드티(모자 내림), 검은 카고 바지, 짧은 머리와 수염 |
| `civilian.glb` | 청록 셔츠, 베이지 면바지, 갈색 구두 |
| `enemy_up.glb` / `civilian_up.glb` | 같은 옷차림으로 두 손을 머리 위로 든 모습(같은 사람을 고친 것이 아니라 새로 그린 그림) |

**권리**: 사용자 계정으로 만든 생성물입니다. 공개하거나 게임을 판매하기 전에 Higgsfield 약관을 확인하세요.
